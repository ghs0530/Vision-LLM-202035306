## 농구공 영역 검출

LAB 색공간으로 변환한 후 CLAHE를 1회 적용해 명암 대비를 개선했다.

이후 5×5 타원형 커널로 Opening과 Closing을 각각 1회 비교했다.

Opening이 노이즈 제거에 더 적합해 최종적으로 2회 적용했다.

2회만 진행한 이유는

5×5 타원형 커널로 Opening을 1회 적용했을 때는 Contour가 8개였지만, 2회 적용했을 때 3개로 줄었다. 3회 적용해도 Contour 개수에 변화가 없어 농구공 형태의 손상을 최소화하기 위해 2회를 선택했다.

Contour를 검출한 후 가장 큰 영역을 농구공으로 선택했다.

## 실행 방법

1. GitHub 저장소를 다운로드하거나 clone한다.
2. 저장소의 최상위 폴더에서 터미널을 실행한다.
3. 필요한 라이브러리를 설치한다.

   `pip install opencv-python numpy matplotlib`

4. 아래 명령어로 실행한다.

   `python 261017/assignment_261017.py`

5. 실행하면 농구공 마스크와 외곽선 검출 결과를 확인할 수 있다.
